## 🔬 八、新增基线实验（DDPG和SAC）

### 实验要求

**方法：** DDPG和SAC（使用stable-baselines3）

**实验配置：**
- 随机种子：`[42, 123, 456, 789, 2024, 3141, 2718, 1618, 1414, 2236]`（10个）
- 每个方法运行10次
- 评估指标：QPS、Latency、Error Rate、CV%

**参考代码：**

```python
# DDPG实验
from stable_baselines3 import DDPG
model = DDPG("MlpPolicy", env, 
             learning_rate=1e-4,
             buffer_size=50000,
             batch_size=64,
             gamma=0.95)
model.learn(total_timesteps=300*iterations_per_episode)

# SAC实验
from stable_baselines3 import SAC
model = SAC("MlpPolicy", env,
            learning_rate=1e-4,
            buffer_size=50000,
            batch_size=64,
            gamma=0.95,
            ent_coef='auto')
model.learn(total_timesteps=300*iterations_per_episode)
```

**实现位置：**
- 建议在 `Control experiment/baselines/` 目录下创建：
  - `ddpg_baseline.py`
  - `sac_baseline.py`

**预计耗时：** 每个方法约1-2小时（10次运行）
