## Phase 1：通过优先级深度强化学习进行探索

### 论文公式对应

**优先级计算**（论文公式5）：
```
pi = (|δi| + ϵ)^α
其中：
- δi = ri + γmax_a' Q_θ'(s'_i, a') - Q_θ(s_i, a_i)  【TD误差】
- ϵ = 10^-6  【避免零优先级】
- α = 0.6    【控制优先级程度】
```

**采样概率**（论文公式6）：
```
P(i) = p_i^α / Σ_k p_k^α
```

**重要性采样权重**（论文公式7）：
```
w_i = (N × P(i))^(-β)
其中：
- β: 0.4 → 1.0 逐步增加
- N: 批次大小
- 归一化：w_i = w_i / max_j(w_j)
```

### 1. 阶段初始化

```
开始Phase 1
    ↓
【核心组件初始化】
    创建优先级经验回放缓冲区:
        ├─ 容量: 50000
        ├─ α (优先级指数): 0.6
        ├─ β (重要性采样): 0.4 → 1.0
        └─ β递增率: 0.001
    ↓
    创建DQN智能体:
        ├─ 状态维度: 10 (5参数 + 5性能指标)
        ├─ 动作维度: 10 (5参数 × 2方向)
        ├─ NAS搜索最优网络架构:
        │   ├─ num_layers: 4
        │   ├─ hidden_dims: [256, 128, 64, 32]
        │   ├─ dropout: 0.2
        │   └─ activation: LeakyReLU
        └─ 双Q网络: Q_online, Q_target
    ↓
    设置训练参数:
        ├─ 总Episodes: 300 (Episode 1→300)
        ├─ 每Episode迭代: 10轮
        ├─ 初始ε: 0.9 (高探索率)
        ├─ 最终ε: 0.1
        ├─ ε衰减率: 0.998
        ├─ 学习率: 1e-4 (Adam优化器)
        └─ γ (折扣因子): 0.99
    ↓
    初始化元学习器（Phase 2准备）:
        └─ MetaLearner(base_model=Q_network)
    ↓
    初始化贝叶斯优化器（Phase 3准备）:
        └─ BayesianOptimizer({lr, γ, ε_decay})
    ↓
进入Episode循环 (Episode = 1)
```

### 2. 单个Episode训练流程（带优先级经验重播）

```
Episode开始 (Episode i, i=1→300)
    ↓
【步骤1：环境重置】
    重置系统参数到基准配置
    ↓
    测量基准性能
    ↓
    初始化Episode状态:
        - current_state = [params_normalized, metrics_normalized]
        - episode_buffer = []  # 本episode的经验
    ↓
【步骤2：调优迭代循环】(10轮)
    For iteration = 1 to 10:
        ↓
        【2.1 状态观察】
            构建状态向量 s_t (10维):
                - 5个内核参数归一化 [0-1]
                - 5个性能指标归一化 [0-1]
        ↓
        【2.2 动作选择】(ε-greedy策略)
            生成随机数 rand ∈ [0,1]
            ↓
            IF rand < ε:  # 探索
                a_t = random.choice({0,1,...,9})
            ELSE:  # 利用
                Q_values = Q_online(s_t)
                a_t = argmax(Q_values)
            ↓
            动作映射到参数调整:
                - 动作0: somaxconn +Δ
                - 动作1: somaxconn -Δ
                - 动作2-9: 其他4个参数的增减
        ↓
        【2.3 参数应用与性能测量】
            应用参数调整
            ↓
            执行微服务工作负载模拟
            ↓
            获取新状态 s_{t+1} 和性能指标
        ↓
        【2.4 奖励计算】
            计算性能变化:
                Δqps = (new_qps - current_qps) / current_qps
                Δlatency = (current_lat - new_lat) / current_lat
                Δerror = (current_err - new_err) / current_err
            ↓
            综合奖励函数:
                r_t = 0.5×Δqps + 0.3×Δlatency + 0.2×Δerror
                    - 0.1×penalty  # 稳定性惩罚
            ↓
            判断是否终止:
                done = (error_rate > 5%) OR (qps < 50)
        ↓
        【2.5 经验存储到优先级缓冲区】
            构建经验元组:
                experience = (s_t, a_t, r_t, s_{t+1}, done)
            ↓
            🔥 推送到优先级缓冲区:
                初始优先级 = max(existing_priorities)
                buffer.push(experience)
                # 新经验赋予最高优先级，确保至少被采样一次
            ↓
            episode_buffer.append(experience)
        ↓
        【2.6 优先级采样与网络更新】
            IF buffer.size() >= batch_size (64):
                ↓
                🔥 优先级采样:
                    # 计算采样概率（论文公式6）
                    priorities = buffer.priorities[:size]
                    probabilities = priorities^α / Σ(priorities^α)
                    ↓
                    # 采样batch
                    indices = sample(size=64, p=probabilities)
                    experiences = [buffer[idx] for idx in indices]
                    ↓
                    # 计算重要性采样权重（论文公式7）
                    weights = (N × probabilities[indices])^(-β)
                    weights = weights / max(weights)  # 归一化
                    ↓
                    # β退火
                    β = min(1.0, β + 0.001)
                ↓
                计算TD误差（论文公式5）:
                    For each sample in batch:
                        # 当前Q值
                        Q_current = Q_online(s_i)[a_i]
                        ↓
                        # 目标Q值
                        Q_target_val = r_i + γ × max_a' Q_target(s'_i)
                        ↓
                        # TD误差
                        δ_i = Q_target_val - Q_current
                        ↓
                        # 加权损失
                        loss_i = w_i × (δ_i)^2
                ↓
                反向传播:
                    optimizer.zero_grad()
                    total_loss = mean(weighted_losses)
                    total_loss.backward()
                    clip_grad_norm_(parameters, max_norm=1.0)
                    optimizer.step()
                ↓
                🔥 更新优先级:
                    For each sample i:
                        new_priority_i = |δ_i| + ϵ
                        buffer.update_priorities(indices, new_priorities)
                    # 关键：根据TD误差更新优先级
                    # TD误差大的样本将有更高采样概率
                ↓
                定期同步目标网络:
                    IF iteration % 10 == 0:
                        Q_target ← Q_online
        ↓
        【2.7 记录最佳参数】
            IF new_qps > best_qps_this_episode:
                best_qps = new_qps
                best_params = current_params
        ↓
    End For (迭代循环结束)
    ↓
【步骤3：Epsilon衰减】
    ε = max(ε × 0.998, 0.1)
    ↓
【步骤4：统计记录】
    记录Episode统计:
        - QPS, Loss, ε
        - 优先级缓冲区统计:
            - 平均优先级
            - 最大/最小优先级
            - β当前值
        - TD误差分布
    ↓
【步骤5：定期评估】
    IF Episode % 50 == 0:
        保存checkpoint
        ↓
        分析优先级重播效果:
            - 高优先级样本占比
            - TD误差收敛曲线
            - 样本多样性指标
    ↓
【步骤6：判断继续或结束】
    IF Episode < 300:
        Episode++
        返回【步骤1】
    ELSE:
        进入【Phase 1结束】
```

## Phase 2：通过元学习进行适应

### 论文公式对应

**元学习目标函数**（论文公式8、9）：
```
min_θ Σ_T L_T(θ')
其中：
- θ' = θ - α∇_θ L_T(θ)  【内循环更新】
- 外循环更新: θ ← θ - β∇_θ Σ_T L_T(θ')
```

**多任务集**：
```
任务集 T = {T1, T2, T3, ...}
- T1: API网关场景
- T2: 负载均衡器场景
- T3: 数据库代理场景
- ...
```

### 1. 阶段初始化

```
开始Phase 2
    ↓
【步骤1：加载Phase 1预训练模型】
    加载 θ_pretrain:
        - Q网络权重 → θ_base
        - 优先级缓冲区 → 继续使用
        - ε = 0.1 → 固定
    ↓
【步骤2：配置元学习器】
    初始化MAML元学习器:
        ├─ base_model: Q_network (θ_base)
        ├─ 内循环学习率 α: 0.01
        ├─ 外循环学习率 β: 0.001
        ├─ 适应步数: 3 steps
        └─ 任务缓冲区: []
    ↓
【步骤3：定义多任务场景】
    任务集定义:
        Task 1: API网关场景
            ├─ 工作负载模式: api_gateway
            ├─ 并发: 50-150
            └─ 请求类型: 混合读写
        ↓
        Task 2: 负载均衡器场景

    ↓
【步骤4：设置训练参数】
    训练配置:
```

### 2. 单个Episode训练流程（带元学习）

```
Episode开始 (Episode i, i=301→350)
    ↓
【步骤1：任务选择与环境配置】
    IF (Episode - 301) % 5 == 0:  # 每5个episodes切换任务
        ├─ 当前任务索引 = ((Episode-301)//5) % 3
        ├─ 
        ├─ 切换工作负载场景:
        │   IF 任务 == Task 1 (API网关):
        │       设置: api_gateway模式
        │   ELIF 任务 == Task 2 (负载均衡):
        │       设置: load_balancer模式
        │   ELIF 任务 == Task 3 (DB代理):
        │       设置: database_proxy模式
        │   
        ├─ 🔥 触发元学习快速适应:
        │   IF task_buffer[current_task].size() > 0:
        │       # 使用该任务的历史经验快速适应
        │       meta_learn(task_buffer[current_task])
        └─ 
    ↓
    重置系统参数到基准配置
    ↓
    测量当前任务的基准性能
    ↓
【步骤2：调优迭代循环】(10轮)
    task_experiences = []  # 收集当前任务的经验
    ↓
    For iteration = 1 to 10:
        ↓
        【2.1 状态观察】
            构建状态向量 s_t:
                - 5个参数归一化
                - 5个性能指标归一化

        【2.3-2.4 参数应用、性能测量、奖励计算】
            (与Phase 1相同)
        ↓
        【2.5 经验存储】
            experience = (s_t, a_t, r_t, s_{t+1}, done)
            ↓
            # 存入全局优先级缓冲区
            buffer.push(experience)
            ↓
            # 🔥 存入任务专属缓冲区（用于元学习）
            task_experiences.append(experience)
        ↓
        【2.6 网络更新】
            优先级采样 + TD误差计算 + 反向传播
            (与Phase 1相同)
        ↓
    End For
    ↓
【步骤3：元学习更新】(🔥 Phase 2关键步骤)
    IF len(task_experiences) >= 10:  # 任务经验足够
        ↓
        🔥【内循环：快速适应当前任务】
            # 创建临时适应模型
            θ_adapted = copy(θ_base)
            ↓
            For adaptation_step = 1 to 3:  # 3步快速适应
                ↓
                # 从任务经验中采样
                task_batch = sample(task_experiences, size=32)
                ↓
                # 计算任务特定损失
                L_task = 0
                task_gradients = []
                For (s, a, r, s', done) in task_batch:
                    Q_val = Q_adapted(s)[a]
                    Q_target = r + γ × max(Q_adapted(s'))
                    loss = (Q_val - Q_target)^2
                    L_task += loss
                ↓
                # 内循环更新（论文公式）
                θ_adapted ← θ_adapted - α∇_{θ_adapted} L_task
                ↓
                task_gradients.append(∇L_task)
            ↓
        🔥【外循环：元更新基础模型】
            # 计算元梯度
            meta_gradient = mean(task_gradients)
            ↓
            # 外循环更新（论文公式）
            θ_base ← θ_base - β × meta_gradient
            ↓
            # 更新主Q网络
            Q_network.load_state_dict(θ_base)
            ↓
            logging.info(f"元学习完成，任务: {current_task}")
        ↓
        # 更新任务缓冲区
        task_buffer[current_task].extend(task_experiences)
    ↓
【步骤4：统计记录】
    记录Episode统计:

        - 当前任务类型
        - 元学习事件:
            - 适应步数
            - 任务损失变化
            - 元梯度范数
        - 跨任务泛化性能
    ↓
【步骤5：定期评估】
    IF Episode % 10 == 0:
        ↓
        保存checkpoint
        ↓
        评估多任务性能:
            For each task in {Task1, Task2, Task3}:
                切换到该任务
                ↓
                测试快速适应能力:
                    - 0-shot性能（未适应）
                    - 1-shot性能（1步适应）
                    - 3-shot性能（3步适应）
                ↓
                记录适应曲线
        ↓
        分析元学习效果:
            - 跨任务泛化能力
            - 快速适应速度
            - 任务间知识迁移
    ↓
【步骤6：判断继续或结束】
    IF Episode < 350:
        Episode++
        返回【步骤1】
    ELSE:
        进入【Phase 2结束】
```

## Phase 3：贝叶斯优化精炼

### 论文描述

**优化空间**（三维）：
```
超参数空间 = {
    learning_rate (lr): [1e-5, 1e-3]
    discount_factor (γ): [0.8, 0.99]
    epsilon_decay: [0.99, 0.9999]
}
```

**目标**：
- 最小化性能变异（σ_QPS）
- 最大化平均QPS

### 1. 阶段初始化

```
开始Phase 3
    ↓
【步骤1：加载Phase 2元学习模型】
    加载 θ_converge:
        - 元学习优化的Q网络 → θ_meta
        - 任务缓冲区
        - ε = 0.1
    ↓
【步骤2：配置贝叶斯优化器】
    初始化BO:
        优化空间:
            ├─ learning_rate: [1e-5, 1e-3]
            ├─ gamma (γ): [0.8, 0.99]
            └─ epsilon_decay: [0.99, 0.9999]
        ↓
        初始采样点:
            - 随机采样5个初始点
            - 评估每个点的性能
            - 建立初始高斯过程模型
    ↓
【步骤3：设置训练参数】
    训练配置:
        - 总Episodes: 50 (Episode 351→400)
        - 每Episode: 10轮迭代
        - 🔥 ε动态调整: 由BO优化
        - 🔥 启用Warm Start: True
        - 基准测量: 3次取中位数
        - BO更新频率: 每5个episodes
    ↓
【步骤4：初始化Warm Start】

    best_hyperparams = {

        'gamma': 0.99,
        'epsilon': 0.1
    }
    ↓
进入Episode循环 (Episode = 351)
```

### 2. 单个Episode训练流程（带BO和Warm Start）

```
Episode开始 (Episode i, i=351→400)
    ↓
【步骤1：贝叶斯优化超参数调整】
    IF (Episode - 351) % 5 == 0:  # 每5个episodes运行BO
        ↓
        🔥【获取BO建议的超参数】
            # 计算过去5个episodes的性能指标
            recent_qps_mean = mean(qps[-5:])
            recent_qps_std = std(qps[-5:])
            ↓
            # 定义优化目标（最小化变异，最大化QPS）
            objective = recent_qps_mean - 0.3 × recent_qps_std
            ↓
            # 更新BO观察
            current_hyperparams = {
                'lr': agent.optimizer.learning_rate,
                'gamma': agent.gamma,
                'epsilon_decay': agent.epsilon_decay
            }
            BO.update(current_hyperparams, objective)
            ↓
            # 获取下一组超参数建议
            suggested_hyperparams = BO.suggest_next_point()
            ↓
            🔥【应用BO建议的超参数】
            agent.optimizer.lr = suggested_hyperparams['lr']
            agent.gamma = suggested_hyperparams['gamma']
            agent.epsilon_decay = suggested_hyperparams['epsilon_decay']
            agent.epsilon = suggested_hyperparams['epsilon']
            ↓
```
