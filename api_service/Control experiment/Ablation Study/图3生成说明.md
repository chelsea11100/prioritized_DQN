# 图3生成说明

## 📋 脚本依赖

### 依赖文件
- **文件名：** `ablation_analysis_results.json`
- **文件说明：** 消融实验的分析结果文件，包含组件贡献度数据

### 文件位置
脚本会按以下顺序查找文件（优先级从高到低）：

1. **当前工作目录下的文件**
   - `./ablation_analysis_results.json`
   - 如果你在同一目录执行脚本，这是最优先的路径

2. **当前工作目录下的标准路径**
   - `./result/消融实验内容/分析数据/ablation_analysis_results.json`

3. **脚本所在目录下的文件**
   - `脚本目录/ablation_analysis_results.json`

4. **脚本所在目录下的标准路径**
   - `脚本目录/result/消融实验内容/分析数据/ablation_analysis_results.json`

5. **项目根目录的相对路径**
   - `Control experiment/result/消融实验内容/分析数据/ablation_analysis_results.json`

6. **递归查找**
   - 如果以上路径都没找到，脚本会在当前工作目录和脚本目录递归查找

### 文件结构要求
文件必须包含以下字段：
```json
{
  "component_contribution": {
    "nas": {
      "absolute": 11.46,
      "percentage": 6.22
    },
    "meta_learning": {
      "absolute": 5.17,
      "percentage": 2.81
    },
    "bayesian_optimization": {
      "absolute": 2.21,
      "percentage": 1.20
    },
    "all_components": {
      "absolute": 16.06,
      "percentage": 8.72
    },
    "synergy_effect": {
      "absolute": -2.77,
      "percentage": -1.51
    }
  }
}
```

## 🚀 使用方法

### 方法1：在同一目录下执行（推荐）
如果你有 `ablation_analysis_results.json` 文件，将其放在脚本同一目录下，然后执行：
```bash
cd "Control experiment/Ablation Study"
python generate_figure3_component_contribution.py
```

### 方法2：在数据文件所在目录执行
```bash
cd "Control experiment/result/消融实验内容/分析数据"
python "Control experiment/Ablation Study/generate_figure3_component_contribution.py"
```

### 方法3：使用标准项目结构
如果文件在标准位置，从项目根目录执行：
```bash
cd "D:\桌面\integration\api_service"
python "Control experiment/Ablation Study/generate_figure3_component_contribution.py"
```

## 📊 输出文件

脚本会在**当前工作目录**下生成以下文件：
- `图3_组件贡献度分析.png` - PNG格式（适合预览）
- `图3_组件贡献度分析.pdf` - PDF格式（适合论文）

## 🔍 文件生成

`ablation_analysis_results.json` 文件通常由以下脚本生成：
- `analyze_ablation_results.py` - 完整分析脚本
- `calculate_ablation_stats.py` - 统计分析脚本

如果文件不存在，请先运行分析脚本生成数据文件。

## ❓ 常见问题

### Q1: 提示"未找到 ablation_analysis_results.json 文件"
**解决方案：**
1. 检查文件是否存在
2. 确认文件名称拼写正确
3. 检查文件路径是否正确
4. 如果文件在其他位置，可以复制到脚本同一目录下

### Q2: 提示"数据文件中缺少 'component_contribution' 字段"
**解决方案：**
1. 检查文件格式是否正确
2. 确认文件是由分析脚本生成的完整结果文件
3. 重新运行分析脚本生成新文件

### Q3: 生成的图片在哪里？
**答案：** 图片会保存在**执行脚本时的当前工作目录**下，不是脚本所在目录。
