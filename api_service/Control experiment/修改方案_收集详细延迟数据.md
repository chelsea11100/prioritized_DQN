# DDPG和SAC - P99数据收集方案

## 问题诊断

### 现有数据的局限性
```
DDPG/SAC结果文件：
  Trial 1: latency = 47.20 ms  (10次模拟的平均)
  Trial 2: latency = 46.62 ms  (10次模拟的平均)
  ...
  Trial 10: latency = 47.23 ms (10次模拟的平均)
  
❌ 只有10个平均值 → 无法计算真实的P99
```

### 其他方法的数据结构
```
Default/Expert/BO/DQN结果文件：
  请求1: latency = 42.5 ms
  请求2: latency = 45.2 ms
  请求3: latency = 38.9 ms
  ...
  请求100: latency = 51.3 ms
  
✅ 有所有原始请求的延迟 → 可以计算真实的P99
```
