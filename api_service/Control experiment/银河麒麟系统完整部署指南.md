# 银河麒麟系统完整部署与运行指南

## 📦 第一步：传输文件到银河麒麟系统

### 1.1 在Windows系统打包

```bash
# 打开命令提示符或PowerShell，进入项目父目录
cd D:\桌面\integration

# 打包整个 api_service 目录（包含Control experiment）
tar -czf api_service.tar.gz api_service/

# 或使用7-Zip等工具压缩为 api_service.zip
```

### 1.2 传输到银河麒麟系统

**方式1：使用 scp（推荐）**
```bash
# 替换为你的麒麟系统IP和用户名
scp api_service.tar.gz username@192.168.x.x:/home/username/
```

**方式2：使用U盘**
1. 将 `api_service.tar.gz` 复制到U盘
2. 插入麒麟系统
3. 复制到用户主目录

**方式3：使用网络共享**
- 通过Samba/NFS等网络共享方式传输



## 🚀 第五步：运行对比实验

### 5.1 进入实验目录

```bash
# 确保虚拟环境已激活
cd ~/api_service/"Control experiment"

# 或者如果路径有空格：
cd ~/api_service/Control\ experiment/
```

### 5.2 检查sudo权限（重要！）

```bash
# 测试是否有sudo权限
sudo -v

# 测试能否修改内核参数
sudo sysctl -w net.core.somaxconn=1024
sudo sysctl -w net.core.somaxconn=128  # 改回默认值

# 如果成功，说明有权限，继续下一步
# 如果失败，实验会使用模拟模式（仍可正常运行）
```

### 5.3 快速测试（1次运行，约5分钟）

```bash
# 先做一次快速测试，确保一切正常
# 使用sudo运行（推荐）
sudo $(which python) -c "
import sys
sys.path.insert(0, '..')
from utils.seeding import set_seed
from baselines.default_baseline import run_default_baseline

set_seed(42)
print('开始测试 Default 基线...')

print(f'✅ 测试成功！结果: {result}')
"

# 如果没有sudo权限，直接运行（会使用模拟模式）：
# python3 -c "..."
```

### 5.4 运行完整实验（25次运行，约2-3小时）

#### 方式1：使用sudo运行（推荐，真实修改内核参数）

```bash
# 确保虚拟环境已激活，然后用sudo运行
cd ~/api_service/"Control experiment"
source ../venv/bin/activate

# 使用sudo运行实验
sudo $(which python) run_comparison_experiment.py

# 或者直接指定虚拟环境的python路径
sudo ~/api_service/venv/bin/python run_comparison_experiment.py

# 实验会自动运行：
# - 5个方法
# - 每个方法5个随机种子
# - 共25次运行
# - 预计耗时：2-3小时
```

#### 方式2：不使用sudo运行（模拟模式，不修改真实内核参数）

```bash
# 如果没有sudo权限或不想修改系统参数
python3 run_comparison_experiment.py

# 注意：
# - 系统会使用模拟器评估性能
# - 不会真实修改内核参数
# - 实验数据仍然有效
# - 会在日志中看到权限警告（可忽略）
```

#### 方式3：后台运行（长时间实验推荐）

```bash
# 使用nohup在后台运行，即使SSH断开也继续
# 使用sudo版本
nohup sudo ~/api_service/venv/bin/python run_comparison_experiment.py > experiment_output.log 2>&1 &

# 或不使用sudo
nohup python3 run_comparison_experiment.py > experiment_output.log 2>&1 &

# 记录进程ID
echo $! > experiment.pid

# 查看实时输出
tail -f experiment_output.log

# 查看进程状态
ps aux | grep run_comparison_experiment
```

#### 方式4：使用screen（推荐，可随时查看）

```bash
# 安装screen（如果没有）
sudo apt install screen

# 创建新的screen会话
screen -S experiment

# 激活虚拟环境
cd ~/api_service/"Control experiment"
source ../venv/bin/activate

# 在screen中运行实验（使用sudo）
sudo $(which python) run_comparison_experiment.py

# 按 Ctrl+A 然后 D 离开screen（实验继续运行）
# 重新连接：screen -r experiment
# 查看所有screen：screen -ls
```

## ⚠️ 常见问题和解决方案

### 问题1: torch安装失败

**错误信息**:
```
ERROR: Could not find a version that satisfies the requirement torch
```

**解决方案**:
```bash
# 方式1：安装CPU版本的PyTorch
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# 方式2：如果有GPU
pip install torch torchvision torchaudio
```

### 问题2: 权限错误（sysctl）

**错误信息**:
```
Permission denied when accessing /proc/sys/net/...
或
sysctl: permission denied on key 'net.core.somaxconn'
```

**原因**: 修改内核参数需要root权限

**解决方案**:

```bash
# === 首选方案：使用sudo运行 ===
cd ~/api_service/"Control experiment"
source ../venv/bin/activate
sudo $(which python) run_comparison_experiment.py

# === 备选方案1：配置无密码sudo（方便但需配置） ===
sudo visudo
# 添加：username ALL=(ALL) NOPASSWD: /usr/sbin/sysctl
# 然后直接运行：
python3 run_comparison_experiment.py

# === 备选方案2：模拟模式（最安全） ===
# 直接运行，忽略权限警告
python3 run_comparison_experiment.py
# 注意：会使用模拟器模式，不真实修改内核参数
# 实验数据仍然有效，可用于论文
```

### 问题3: 内存不足

**错误信息**:
```
MemoryError or Killed
```

**解决方案**:
```bash
# 检查内存
free -h

# 如果内存不足，编辑配置减少并发：
# 编辑 ../improved_microservice_workload.py
# 将 base_concurrent_users 从 50 改为 20
# 将 peak_concurrent_users 从 150 改为 50
```

### 问题4: 实验中断

**解决方案**:
```bash
# 实验会保存中间结果
# 查看已完成的部分
cd results/
ls -lh raw_results_*.json

# 可以手动从中断处继续，或重新运行
```
