# 对比实验（论文第5.2节）

## 一、实验目标

对比5种不同方法的性能表现，验证V9-Full方法的有效性。

## 二、对比方法设计

### 5种对比方法

1. **Default（静态默认配置）**
   - 使用系统默认的内核参数
   - 不进行任何调优操作
   - 作为零优化基线

2. **Expert（专家经验调优）**
   - 基于Red Hat推荐配置
   - 手工设置的固定参数组合
   - 代表生产环境常见做法

3. **Bayesian-Opt（贝叶斯优化）**
   - 黑盒优化方法
   - 代表SMAC/BestConfig等工具
   - 通过20次评估搜索最优配置
   - 参考 SMAC/BestConfig 等工具的思路
   - 简化实现：基于历史数据，在最佳点附近探索
    工作流程：
    前2次迭代：随机采样参数
    后续迭代：找到历史最佳点，在其附近添加噪声进行探索
    每次评估后更新历史数据和最佳点

4. **Prioritized-DQN（仅优先级经验回放）**
   - 基础Prioritized DQN
   - 无元学习、贝叶斯优化、NAS增强
   - 用于消融对比
   - 
    参考 Schaul et al. (ICLR 2016) 的 Prioritized DQN 论文
    使用 PyTorch 实现神经网络，未使用第三方 RL 库（如 stable-baselines3、ray）
    核心组件：
       PrioritizedReplayBuffer：优先级经验回放缓冲区
    使用 TD-error 作为优先级
    重要性采样（importance sampling）修正偏差
    DQN网络：使用 PyTorch 的 nn.Module实现
     输入层：10维状态
     隐藏层：255→156→209→101（通过NAS搜索得到）
    输出层：10维Q值


5. **V9-Full（本文完整方法）**
   - Prioritized DQN + 元学习 + 贝叶斯优化 + NAS
   - 多算法协同优化
   - 论文主要方法

## 三、实验执行流程

### 1. 准备工作

- 检查Phase 3最终模型是否存在（`enhanced_dqn_checkpoint_v9_final.pkl`）
- 如果不存在，提示用户先完成Phase 3训练

### 2. 随机种子设置

- 使用10个固定随机种子：`[42, 123, 456, 789, 2024, 3141, 2718, 1618, 1414, 2236]`
- 每个方法在每个种子下运行一次
- 总运行次数：5种方法 × 10个种子 = 50次

### 3. 单次试验执行流程

对每个方法、每个种子：

**步骤1：设置随机种子**
- 设置Python、NumPy、PyTorch的随机种子，保证可复现

**步骤2：执行方法**
- **Default**：直接读取系统默认参数，测量性能
- **Expert**：加载专家配置JSON，应用参数，测量性能
- **Bayesian-Opt**：运行20轮贝叶斯优化，每轮评估一次，选择最优配置，测量性能
- **Prioritized-DQN**：加载预训练模型（禁用增强功能），执行25轮调优，测量性能
- **V9-Full**：加载Phase 3最终模型（启用所有增强），执行25轮调优，测量性能

**步骤3：收集指标**
- QPS（每秒查询数）
- Latency（平均延迟，毫秒）
- Error Rate（错误率）
- Success Rate（成功率）
- CPU Usage（CPU利用率）
- Memory Usage（内存占用）

**步骤4：记录结果**
- 将指标与元数据（方法名、种子、时间戳）保存到结果字典

### 4. 统计计算

**对每个方法：**
- 计算10次运行的均值与标准差
- 计算各指标的均值、标准差、最小值、最大值、中位数

**输出示例：**
```
V9-Full:
  QPS: 185.32 ± 8.45
  延迟: 45.23 ± 2.15 ms
  错误率: 0.0012 ± 0.0003
  成功率: 0.9988
```

### 5. 显著性检验

**检验方法：Welch t-test（双侧）**
- 原假设H0：V9-Full的QPS与其他方法无显著差异
- 备择假设H1：V9-Full的QPS显著优于其他方法
- 显著性水平：α = 0.05

**执行过程：**
- 提取V9-Full的10个QPS值
- 对每个基线方法，提取其10个QPS值
- 执行Welch t-test（不假设方差相等）
- 计算t统计量和p值
- 若p < 0.05，认为差异显著

**输出示例：**
```
V9-Full vs Default:
  t统计量 = 12.3456
  p值 = 0.000001 (显著)
  
V9-Full vs Bayesian-Opt:
  t统计量 = 1.2345
  p值 = 0.123456 (不显著)
```

### 6. 结果保存

**生成的文件：**
1. **原始数据JSON**：所有50次运行的完整数据
2. **统计摘要JSON**：每个方法的均值±标准差
3. **显著性检验JSON**：所有t-test结果
4. **CSV表格**：论文用对比表格（方法、QPS、延迟、错误率、显著性标记）
5. **LaTeX表格**：可直接插入论文的LaTeX格式表格

**LaTeX表格特点：**
- V9-Full行加粗突出
- 显著性差异用**标记
- 包含均值±标准差格式
- 符合学术论文规范

## 四、实验设计要点

### 1. 公平性保证
- 所有方法使用相同的随机种子序列
- 所有方法在相同系统环境下运行
- 所有方法使用相同的评估指标和测量方法

### 2. 可复现性
- 固定随机种子
- 记录完整配置信息
- 保存原始数据供后续分析

### 3. 统计严谨性
- 10个独立运行（10个不同种子）
- 使用Welch t-test（不假设方差相等）
- 报告效应量（Cohen's d，在补充实验中）

### 4. 基线选择合理性
- Default：零优化基线
- Expert：生产环境常见做法
- Bayesian-Opt：黑盒优化强基线
- Prioritized-DQN：消融对比基线

## 五、实验输出解读

### 成功标志
- V9-Full的QPS显著优于Default、Expert、Prioritized-DQN（p < 0.05）
- V9-Full的QPS与Bayesian-Opt无显著差异或更优
- V9-Full的标准差较小（稳定性好）

### 论文描述示例
> "实验结果表明，V9-Full方法在QPS指标上达到185.32±8.45，显著优于Default（135.21±3.45，p<0.001）、Expert（162.15±4.12，p<0.01）和Prioritized-DQN（145.11±37.14，p<0.05）。与Bayesian-Opt（189.45±4.31）相比无显著差异（p=0.123），但标准差更小，表明V9-Full具有更好的稳定性。"

## 六、实验时间估算

- 每个方法单次运行：约1-3分钟
- 总运行次数：50次
- 预计总耗时：1.5-3小时

## 七、实验改进历程

### 改进点

1. **测量稳定性**
   - 从3次测量增加到10次，降低随机波动

2. **DQN探索率**
   - epsilon从1.0降到0.05-0.08，减少随机探索

3. **实验规模**
   - 随机种子从5个增加到10个，提高统计可靠性

4. **迭代轮次**
   - DQN从15轮增加到25轮，给予充分探索机会
